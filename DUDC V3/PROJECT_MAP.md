## 3. كتالوج الملفات والمسؤوليات (File Responsibilities & Functions)

### 3.1. `app_server.py` (قلب الخادم الخلفي)
- **المسؤولية:** خادم HTTP محلي، إدارة الجلسات، التوجيه API، التصدير، إدارة الملفات، والطباعة عبر Edge.
- **أهم الدوال والمتغيرات:**
  - `start_server(port=8765)`: تشغيل الخادم وقتل أي عملية سابقة على المنفذ.
  - `export_certificate_pdf(cert_html, output_pdf_path)`: تصدير PDF فوري عالي الدقة عبر متصفح Microsoft Edge بنمط Headless وبدون هوامش أو ترويسات مزعجة.
  - `open_folder_picker(initial_dir)`: فتح مستعرض المجلدات الأصلي في نظام ويندوز.
  - `do_GET` / `do_POST`: موجهات الـ API ومطابقة المسارات.
  - `CURRENT_PARCELS`: مصفوفة قطع الأراضي المحملة حالياً في الذاكرة.
  - `OUTPUT_DIR`: مجلد الحفظ المختار والمعتمد.

### 3.2. `index.html` (تطبيق الصفحة الواحدة SPA)
- **المسؤولية:** الواجهة الرسومية الكاملة، إدارة الحالات، المحرر التفاعلي للشهادة، ومعالجة الأحداث.
- **أقسام الصفحة والـ DOM الرئيسية:**
  - `#stage1View`: واجهة سحب ملف الرفع، جدول التحقق من التفاوت القانوني، قائمة المراكز (18 مركزاً)، وزر `📁 إضافة صورة من الجهاز` فوق كل صورة.
  - `#stage2View`: استوديو التحرير المتكامل، أشرطة السلايدر للتباعد والهوامش، كارت العلامة المائية، نافذة القص والضبط (`#imageModalBackdrop`)، والشهادة الرسمية (`#certPage` و `#certPaper`).
  - `#stage3View`: ملخص الإخراج وأزرار الطباعة والتصدير.
- **أهم دوال جافاسكريبت:**
  - `switchStage(n)`: التنقل السلس بين المراحل الثلاث (1، 2، 3).
  - `syncStage1ToStage2()`: مزامنة بيانات المواطن والمركز والأضلاع والصور إلى الشهادة.
  - `triggerImageUpload(type)` / `handleImageFileSelected()`: رفع ومعالجة الصور المخصصة من الجهاز.
  - `buildStandaloneCertificateHtml()`: استخراج كود الشهادة النظيف وتجريده من أدوات التحرير لتصدير الـ PDF عبر الباك إند.
  - `triggerPdfPrint()`: تشغيل الطباعة الفورية وتوريث اسم العميل والمركز كعنوان للمستند تلقائياً.

### 3.3. `geo_engine.py` (محرك المساحة والحسابات الجغرافية)
- **المسؤولية:** قراءة ملفات Excel/CAD واستخراج الحدود والإحداثيات والتحقق من القوانين المنظمة.
- **أهم الدوال:**
  - `parse_excel_survey(file_path)`: قراءة جداول النقاط والأضلاع واستخراج أرقام النقط والإحداثيات (X, Y) وأطوال الأضلاع والمجاورين.
  - `clean_num_str(val)` / `clean_text_val(val)`: تنظيف وتوحيد الأرقام والنصوص وإزالة الشوائب.
  - `validate_and_enrich_parcel(parcel)`: حساب مساحة المضلع (Shoelace formula)، وحساب الفرق مع المساحة المذكورة ومطابقتها مع حد التسامح (±2.00 م²).

### 3.4. `croquis_engine.py` (محرك رسم الكروكي الهندسي)
- **المسؤولية:** إنشاء رسم كروكي مطابق للرسم المساحي الهندسي مع تسمية الأضلاع بأطوالها ونقاطها والاتجاهات الجغرافية.
- **أهم الدوال:**
  - `generate_croquis_image(parcel, output_path, ...)`: توليد صورة PNG للكروكي بأبعاد واضحة وألوان متناسقة، ودعم التشكيل العربي عبر `arabic_reshaper` و `bidi`.

### 3.5. `satellite_engine.py` (محرك الصور الفضائية)
- **المسؤولية:** سحب وتوليد لقطة فضائية حقيقية للموقع الجغرافي من مصادر الأقمار الصناعية ورسم حدود القطعة فوقها.
- **أهم الدوال:**
  - `generate_satellite_image(parcel, output_path)`: تحديد المربع الجغرافي (Bounding Box) ومستوى التكبير وحفظ الصورة الناتجة في مسار الكاش.

### 3.6. `encoder_api.py` (محرك التأمين والرقابة السحابية)
- **المسؤولية:** توليد وتأكيد كود التأمين الرقابي (DUDC Token) وحمايته ضد التزييف.
- **أهم الدوال:**
  - `generate_dudc_token(...)`: استدعاء خدمة Modal السحابية مع وجود بديل تشفير محلي آمن ومباشر (SHA-256 Base62) في حال انقطاع الإنترنت أو بطء الاستجابة لضمان استمرارية العمل أوفلاين دون توقف.

### 3.7. `centers.py` (قاعدة بيانات المراكز الرسمية)
- **المسؤولية:** تعريف المراكز الـ 18 لمحافظة الدقهلية بأرقامها التعريفية ومطابقة الأسماء مع مراعاة الاختلافات الإملائية للهمزات والتاء المربوطة.
- **أهم العناصر:**
  - `DAKAHLIA_CENTERS`: مصفوفة المراكز الرسمية (المنصورة، طلخا، ميت غمر، دكرنس، بلقاس، شربين، ... إلخ).
  - `normalize_arabic(text)`: دالة تجريد وحذف السوابق الإدارية (مركز، مدينة، حي) والهمزات للمقارنة الدقيقة.

## 4. جدول واجهات برمجة التطبيقات (REST APIs Reference)

| المسار (Route) | الطريقة (Method) | المدخلات (Payload) | المخرجات (Response) | الوظيفة |
|---|---|---|---|---|
| `/api/health` | GET | لا يوجد | `{"status": "ok"}` | فحص استجابة الخادم وحالة الاتصال |
| `/api/get-output-dir` | GET | لا يوجد | `{"output_dir": "..."}` | جلب مسار مجلد الإخراج الحالي |
| `/api/get-defaults` | GET | لا يوجد | `{"defaults": {...}}` | استعادة الإعدادات المحفوظة للاستوديو |
| `/api/get-centers` | GET | لا يوجد | `{"centers": [[0, "المنصورة"], ...]}` | جلب قائمة المراكز الـ 18 الرسمية |
| `/api/list-drafts` | GET | لا يوجد | `{"success": true, "drafts": [...]}` | جلب قائمة المسودات المحفوظة وتفاصيلها |
| `/api/save-draft` | POST (JSON) | بيانات الجلسة والشهادة | `{"success": true, "draft_id": "..."}` | حفظ أو تحديث مسودة شهادة في مجلد drafts |
| `/api/load-draft` | POST (JSON) | `{"draft_id": "..."}` | `{"success": true, "session": {...}}` | تحميل مسودة وإعادة ضبط القطعة الحالية والصور |
| `/api/delete-draft` | POST (JSON) | `{"draft_id": "..."}` | `{"success": true}` | حذف مسودة محددة يدوياً من صندوق المسودات |
| `/api/upload` | POST (Multipart) | ملف الرفع Excel | `{"success": true, "parcels": [...]}` | قراءة ملف الرفع وتحليله وحساب تفاوت المساحة |
| `/api/preview-croquis` | POST (JSON) | `{"parcel_index": 0, "font_size_..."}` | `{"croquis_url": "..."}` | توليد وتحديث صورة الكروكي بالخطوط المختارة |
| `/api/preview-satellite`| POST (JSON) | `{"parcel_index": 0}` | `{"image_url": "..."}` | توليد وتحديث صورة القمر الصناعي للموقع |
| `/api/upload-parcel-image` | POST (JSON) | `{"type": "croquis/satellite", "image_base64": "..."}` | `{"success": true, "saved_path": "..."}` | حفظ صورة مخصصة مرفوعة من جهاز المستخدم |
| `/api/browse-output-dir` | POST (JSON) | `{"initial_dir": "..."}` | `{"folder_path": "..."}` | فتح مستعرض ويندوز لاختيار مجلد الحفظ |
| `/api/update-center` | POST (JSON) | `{"center_id": 1, "center_name": "..."}` | `{"security_token": "...", ...}` | تأمين القطعة وتوليد كود الحماية للمركز |
| `/api/export-package` | POST (JSON) | بيانات الشهادة الكاملة + كود الـ HTML | `{"success": true, "folder_path": "...", "files": {...}}` | توليد حزمة المخرجات الكاملة (PDF, JSON, Images, Survey) وحذف المسودة آلياً |
| `/api/open-folder` | POST (JSON) | `{"folder_path": "..."}` | `{"success": true}` | فتح مجلد المخرجات في مستكشف ويندوز Explorer |

## 5. مصفوفة "أين أعدل الكود؟" (Developer Decision Matrix)

عند الرغبة في تعديل أي سلوك أو إصلاح أي مسألة، توجه مباشرة للملف والسطر الموضح بالجدول:

| الهدف أو التعديل المطلوب | الملف المعني | التفاصيل ومكان العمل |
|---|---|---|
| **تعديل نصوص الشهادة أو التنسيق المرئي الحي** | `index.html` | التوجه لقسم `#stage2View`، والتحكم في كلاسات CSS والهوامش التلقائية. |
| **صندوق المسودات والحفظ المؤقت للشهادات** | `app_server.py` + `index.html` | مجلد `drafts/`، أزرار المسودات والمودال `#draftsModalBackdrop`. |
| **تغيير ألوان أو خطوط أو أرقام كروكي الموقع CAD** | `croquis_engine.py` | تعديل الدالة `generate_croquis_image` وإعدادات Matplotlib. |
| **تعديل منطق قراءة أعمدة ملف Excel أو حساب التفاوت** | `geo_engine.py` | تعديل `parse_excel_survey` و `validate_and_enrich_parcel`. |
| **تعديل تسمية ملفات ومجلدات التصدير النهائي** | `app_server.py` | مراجعة المسار `/api/export-package` (أسماء الملفات: `[العميل]-[المركز]`). |
| **تعديل زر أو سلوك رفع الصور من الجهاز** | `index.html` | دالة `triggerImageUpload` والـ input الخاص بالمرحلة الأولى. |
| **تعديل طباعة وتصدير ملف الـ PDF** | `app_server.py` + `index.html` | دالة `export_certificate_pdf` في الباك إند وقواعد `@media print` في الفرونت إند. |
| **إضافة أو تعديل مراكز محافظة الدقهلية** | `centers.py` | مصفوفة `DAKAHLIA_CENTERS` ودالة `normalize_arabic`. |

## 6. قواعد ومحددات صارمة للنظام (Core Rules & Invariants)

1. **التعامل مع البيانات الناقصة:** في حال خلو خانة الرقم القومي، رقم الإيصال، أو رقم الطلب؛ يُمنع منعاً باتاً وضع بيانات وهمية أو تجريبية، ويجب أن تظهر عبارة **"لا يوجد بيانات متاحة"**.
2. **تسمية المخرجات:** مجلد العميل وكافة ملفات التصدير تُسمى حصراً بالنمط:  
   `[اسم العميل]-[المركز]`  
   - مثال: `أحمد محمد إبراهيم-طلخا.pdf`  
   - مثال: `أحمد محمد إبراهيم-طلخا_session.json`  
3. **أزرار الواجهة:** أزرار رفع الصور المخصصة تظهر **فقط في المرحلة الأولى (المطابقة والإدخال)**، وتختفي تماماً في المرحلة الثانية والاستوديو لضمان نظافة المستند عند الطباعة المباشرة.
4. **ملف الجلسة JSON:** يدمج بيانات الصورتين (الكروكي والقمر الصناعي) بتنسيق Base64 مباشرة داخل الملف لتمكين استعادة التعديلات في أي وقت دون فقدان الصور.
