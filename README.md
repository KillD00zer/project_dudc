## 🚀 ما الجديد في الإصدار الرابع DUDC V4.0؟ (Release Highlights)
1. **البيئة المحمولة المستقلة بالكامل (Zero-Install & Zero-Internet Portable Runtime):**
   - تم تزويد المنظومة ببيئة بايثون مدمجة مستقلة 32-بت (`runtime\`) مهيأة بجميع الحزم الرياضية والجيوديسية مسبقة الترجمة (`numpy`, `pandas`, `shapely`, `pyproj`, `matplotlib`, `pillow`, `arabic-reshaper`, `python-bidi`).
   - تشغيل فوري بدون أي تثبيت أو تنزيل من الإنترنت.
   - تعمل بكفاءة تامة على الأجهزة القديمة ومحدودة الموارد (Windows 32-bit وذاكرة 4GB RAM) وكذلك الأجهزة الحديثة 64-bit.
2. **المعالجة الجذرية لمحرك النصوص العربية بالكروكي (RTL & Bidi Engine):**
   - فحص تلقائي وتوافق ذكي مع مكتبات Matplotlib و HarfBuzz لمنع انعكاس الحروف العربية على مختلف أنظمة ويندوز.
   - مصفوفة خطوط احتياطية (`CROQUIS_FONT_FAMILIES`) لضمان وضوح الأبعاد وأسماء الواجهات والحدود.
3. **تصدير الـ PDF المتجهي وحفظ التظليلات الرسمية:**
   - ضبط قواعد وسائط الطباعة ومحرك Chromium/Edge لإجبار طباعة التظليلات الرسمية اللبنية (`#D3DFEE`) لعناوين الأقسام والجداول.
4. **تحديث الكوادر الفنية:**
   - إدراج الفني المساحي "السيد جاد" في قوالب الشهادات وتوقيعات الاستخراج الرسمية.

## 📖 نظرة عامة / Overview
منظومة تفاعلية متكاملة وشاملة صممت خصيصاً لمهندسي وفنيي المساحة بمركز معلومات شبكات المرافق بمحافظة الدقهلية لإدارة دورة عمل شهادات الصلاحية والرفع المساحي والتحقق الجيوديسي، وتوليد الخرائط والكروكيات الهندسية، مع تأمين المستندات رسمياً ومطابقتها بالتفاوت القانوني المعتمد وإصدار حزم المخرجات بصيغة PDF متجهة فائقة الجودة.

تمت إعادة هيكلة المنظومة وتطبيق **المعيارية الشاملة (Modularity)** لفصل النواة الهندسية تماماً في حزمة بايثون مستقلة (`core_gis`) يمكن إعادة استخدامها في برامج نظم المعلومات الجغرافية (مثل ArcGIS Pro و QGIS) أو كأدوات سطر أوامر، مع تفكيك السيرفر والواجهة الأمامية لمنع التعارض وتسهيل التحديث المستمر.

كما تم تطوير **مستعرض مجلدات مرئي مدمج (In-App Visual Explorer)** يعمل داخل المتصفح بنسبة 100% وبدون استدعاء PowerShell أو أوامر Shell نهائياً، مما يقضي تماماً على مشاكل التعليق أو النوافذ المخفية على كافة أجهزة العمل.

## 🚀 كيفية إعادة استخدام النواة الهندسية (`core_gis`) في مشاريع خارجية

بفضل تفكيك النواة، يمكنك الآن استيراد المحركات في أي سكربت خارجي أو أداة GIS دون الحاجة لتشغيل السيرفر أو الواجهة:

```python
import sys
sys.path.append("d:/Work/GIS_tools/project_dudc/DUDC V3")

# استيراد النواة الهندسية
import core_gis

# 1. قراءة ملف رفع مساحي وحساب التفاوت القانوني
parcels = core_gis.read_survey_file("مسار_ملف_الرفع.xls")
p = parcels[0]
print(f"المساحة المحسوبة: {p['calculated_area_m2']} م²")
print(f"مطابقة التفاوت (±2م²): {p['is_area_valid']}")

# 2. توليد صورة كروكي CAD هندسي عالي الدقة (Thread-Safe)
core_gis.generate_croquis_image(p, "output_croquis.png", font_size_pts=14)

# 3. جلب وتجميع صورة القمر الصناعي مع رسم حدود المضلع
core_gis.generate_satellite_image(p, "output_satellite.jpg")

# 4. مطابقة وتصحيح اسم المركز إدارياً
is_match, center_id, canon_name = core_gis.resolve_center("مركز المنصورة")
print(f"المركز الرسمي: {canon_name} (معرف: {center_id})")
```

## 📂 نظام اختيار مجلد الحفظ المرئي المقاوم للمشاكل (Resilient Folder Selection)

تمت إعادة تصميم مكون اختيار مجلد الحفظ بالكامل لحل مشاكل الشيل (Shell / PowerShell) التي كانت تظهر على بعض أجهزة فنيي المساحة (مثل ظهور النافذة في الخلفية، تعليق السيرفر، أو قيود صلاحيات AppLocker / Antivirus):

1. **المستعرض المرئي المدمج (In-App Visual Explorer):**
   - واجهة مرئية بالكامل تعمل داخل المتصفح بنسبة 100%.
   - تعتمد على دوال بايثون المباشرة (`os.scandir`) دون إطلاق أي عمليات Shell أو PowerShell خارجية.
   - تصفح الشجرة والمجلدات بسهولة وإنشاء مجلدات جديدة بضغطة زر (`➕ مجلد جديد`).
2. **الوصول السريع بنقرة واحدة (1-Click Quick Locations):**
   - استدعاء مباشر لسطح المكتب، المستندات، مجلد حفظ المنظومة، والأقراص المتصلة (`C:\`, `D:\`, ...) بنقرة واحدة.
3. **التحقق اللحظي التلقائي (Live Validation):**
   - فحص وجود المسار وصلاحية الكتابة فيه فور كتابته، مع التنبيه الذكي في حال كان المجلد غير موجود وسيتم إنشاؤه تلقائياً عند حفظ الشهادة.
4. **التوافق التدرجي مع نظام ويندوز (Graceful Native Fallback):**
   - زر "🪟 ويندوز" يعتمد أولاً على نافذة Tkinter الأصلية السريعة (بدون شل)، ثم خيار PowerShell كنافذة ذات أولوية عليا (`TopMost`) مع رابط فوري للمستعرض المدمج في حال حدوث أي تأخير.

## ⚡ البدء السريع والتشغيل اليومي

1. اضغط نقراً مزدوجاً على **`Run_DUDC_V3.bat`** في المجلد الرئيسي.
2. تفتح الواجهة التفاعلية تلقائياً في المتصفح: `http://127.0.0.1:8765`.
3. اضغط على **`⚡ تجربة العينة المرفقة (ف.xls)`** للتحقق الفوري من سير العمل.
4. للتحديث السريع من GitHub، شغّل **`Update_DUDC_V3.bat`**.

## 🔒 القواعد والمحددات الصارمة
1. **معيار التفاوت القانوني:** تطبيق شرط الدقة المساحية الصارم ($\pm 2.0\text{ م}^2$).
2. **كود التأمين (DUDC Token):** يعمل عبر واجهة سحابية مركزية موثقة لمنع التزوير.
3. **تسمية المخرجات:** يتم حفظ كل حزمة في مجلد مستقل باسم `[اسم العميل]-[المركز]`.
