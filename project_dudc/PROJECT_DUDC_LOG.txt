1. EXECUTIVE SUMMARY & PROJECT GOAL (ملخص المشروع والهدف)
----------------------------------------------------------------------------------------------------
Project DUDC is an interactive desktop and web-based cadastral survey certificate generation system
tailored specifically for the Dakahlia Utility Data Center (مركز معلومات شبكات المرافق بمحافظة الدقهلية).

Primary Business Workflow:
  1. Citizen submits a land survey request.
  2. Field surveyors record perimeter boundary coordinates in an Excel sheet (.xls / .xlsx) or CSV.
  3. The surveyor launches Project DUDC (no installation or Python required).
  4. The file is parsed instantly:
     - Geodesic area is calculated on the WGS84 ellipsoid.
     - Stated area vs. calculated area is verified against the legal tolerance of +/- 2.0 m2.
     - Google Satellite high-resolution imagery (Zoom 18-21) is fetched and overlaid with the parcel.
     - Surveyor inspects or edits neighbor boundary descriptions (الحد البحري، الشرقي، القبلي، الغربي).
  5. The surveyor clicks to generate an aligned 300 DPI CAD Croquis (كروكي هندسي) with edge dimensions.
  6. The surveyor selects the responsible staff members from dropdown lists:
     - Survey Technician (فني المساحة)
     - Systems / GIS Officer (مسؤول النظم)
  7. The system produces an official, print-ready Microsoft Word certificate (.docx) matching the 
     official government template, saving it inside a dedicated citizen folder alongside all assets.

  - In `docx_builder.py`, `update_signature_names(doc, survey_tech, sys_officer)` dynamically updates
    the 4-column signature paragraph at the bottom of the Word certificate (` شهادة.docx`):
    * Col 1: فني مساحة          -> أ / {survey_technician}
    * Col 2: مسئول النظم         -> أ / {system_officer}
    * Col 3: رئيس قسم النظم     -> م / محمد مصطفى (Fixed Dept Head)
    * Col 4: مدير المركز         -> م / السيد زين العابدين (Fixed Center Director)
    * Strict 126-character spacing is preserved so columns align with sub-character accuracy without wrapping.

[Change 2] CAD Drawing: Segment Lengths Printed INSIDE the Shape:
  - In `croquis_engine.py`, segment dimension labels (`XX.XXم`) were previously offset along the outward normal.
  - They are now precisely calculated and rendered along the INWARD normal vector (`in_nx = -out_nx`, `in_ny = -out_ny`).
  - An adaptive offset ensures that labels sit cleanly inside the boundary without jumping across opposite edges.
  - This eliminates collision with outer neighbor labels and matches cadastral drafting standards.

[Change 3] CAD Drawing: Reduced & Refined Vertex Numbers Font:
  - Previously, vertex numbers were rendered at `fontsize=16`, which overwhelmed small parcels.
  - The font size has been reduced to `11 pt` bold, and vertex marker circle nodes reduced from `9` to `7.5 pt`.
  - Position offsets are calibrated (`max(span_x, span_y) * 0.038`) to keep point identifiers crisp and tight.

[Change 4] Borders & Neighbors Cleared by Default:
  - Previously, `geo_engine.py` defaulted missing boundary columns to dummy values:
    north: address, south: "أرض فضاء", east: "مبنى سكني", west: "مبنى سكني".
  - This caused unedited certificates and CAD drawings to print placeholder text.
  - Now, `geo_engine.py` defaults all 4 boundaries strictly to empty strings `""`.
  - In `index.html`, inputs start completely blank with subtle placeholders ("اتركه فارغاً أو اكتب اسم الجار / الشارع").
  - If the user leaves them empty, both the CAD drawing and the Word certificate leave neighbor fields completely blank.
  - If the user types neighbor names, they appear outside the CAD perimeter in bold blue and populate Table 0 Column 1.

[Change 5] Official Word Certificate Template Upgrade (7-Column Layout):
  - Upgraded to the official 7-column layout based on `نموذج_شهادة_رسمية_عينة.docx`.
  - `شهادة.docx` in both `project_dudc/` and `src/` matches the official template.
  - `docx_builder.py` maps:
    * Col 0: Direction / Point Name (الحد البحري، الحد الشرقي، إلخ)

4. SYSTEM ARCHITECTURE & CORE ENGINES (المحركات الهندسية التفصيلية)
----------------------------------------------------------------------------------------------------

A. Survey Data Parser & Spatial Math Engine (`geo_engine.py`):
   - Supports: `.xls` (BIFF8 via `xlrd`), `.xlsx` (OpenPyXL), and `.csv` (UTF-8 / UTF-8-BOM / CP1256).
   - Dynamic fuzzy column discovery handles various naming conventions.
   - Geodesic Calculation: Uses `pyproj.Geod(ellps='WGS84')` for true ellipsoidal surface area.
   - Tolerance Rule: Computes Δ = `calculated_area_m2 - stated_area_m2`. Legal pass if `|Δ| <= 2.0 m²`.

B. High-Resolution CAD Croquis Engine (`croquis_engine.py`):
   - Renders at 300 DPI on pure white background using Matplotlib `Agg`.
   - Metric Cartesian projection centered on centroid.
   - Vertices: Bright green circular nodes (`#00E676`) with 11 pt red point numbers (1..N).
   - Edge Dimensions: Dimension length in meters (`XX.XXم`) printed in bold red (`#D32F2F`) INSIDE the polygon.
   - Neighbor Annotations: Bold blue neighbor descriptions (`#0284C7`) OUTSIDE the polygon (only if provided).
   - Orientation & North Arrow: Semi-transparent black compass arrow widget (`N`) anchored at top-left.

C. Google Satellite Imagery Engine (`satellite_engine.py`):
   - Automatically computes adaptive zoom level (18 to 21) based on parcel area span.
   - Downloads Google Satellite Web Mercator tiles, stitches them into a multi-tile mosaic,
     and overlays a translucent red polygon fill and bold 5 px red boundary stroke.

D. Word Certificate Publisher (`docx_builder.py`):
   - Direct XML-level manipulation of `شهادة.docx` using `python-docx`.
   - Populates applicant information and dynamic vertex rows.
   - Injects CAD Croquis (3.05 in) and Satellite (3.05 in) into the final row.
   - Updates employee signature paragraph with selected technician & systems officer.
   - Zeroes out all paragraph and table spacing to guarantee a strict single-page printout.

E. Web Server & API Controller (`app_server.py`):
   - Native Python `HTTPServer` running locally on `http://127.0.0.1:8765`.
   - Endpoints:
     * `GET  /`                    : Serves `index.html`.
     * `POST /api/load-sample`      : Loads built-in `ف.xls`.
     * `POST /api/upload`           : Receives uploaded `.xls` / `.xlsx` / `.csv` multipart data.
     * `POST /api/preview-satellite`: Generates or returns cached satellite preview image.
     * `POST /api/preview-croquis`  : Generates CAD croquis (inside lengths, optional outer neighbors).
     * `POST /api/upload-image`     : Receives custom base64 image (satellite or croquis).
     * `GET  /api/get-output-dir`   : Returns current output folder.
     * `POST /api/set-output-dir`   : Updates output folder.
     * `POST /api/generate`         : Produces official certificate, images, and copies survey file.
     * `POST /api/open-folder`      : Opens output directory in Windows File Explorer.
