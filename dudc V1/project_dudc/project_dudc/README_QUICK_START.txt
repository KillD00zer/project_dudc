================================================================================
                    PROJECT DUDC - PORTABLE DISTRIBUTION
      Cadastral Survey Certificate System / منظومة إصدار شهادات الرفع المساحي
                 Dakahlia Utility Data Center (DUDC)
================================================================================

[EN] QUICK START GUIDE:
-----------------------
1. Just double-click "Run_DUDC_App.bat" or "Certificate_Generator.exe".
2. The application will launch and automatically open in your web browser.
3. Step 1: Drag & drop your survey file (.xls, .xlsx, or .csv) or click 
           "⚡ Quick Test: Load Built-in Sample (ف.xls)".
4. Step 2: Review verification badge (±2.0 m² area check), preview images 
           (Google Satellite and CAD Croquis), and review boundary descriptions.
5. Step 3: Click "Generate Official Certificate (.docx)".
6. The generated certificates are saved in the "generated_certificates" folder.

[AR] دليل التشغيل السريع:
-----------------------
1. قم بالضغط مرتين على "Run_DUDC_App.bat" أو "Certificate_Generator.exe".
2. سيفتح البرنامج تلقائياً في المتصفح.
3. الخطوة 1: اسحب ملف الرفع المساحي (.xls أو .xlsx أو .csv) أو اضغط على تجربة العينة المرفقة (ف.xls).
4. الخطوة 2: راجع حالة المطابقة المساحية (فرق المساحة المسموح به ±2.0 م²)، وعاين الكروكي وصورة القمر الصناعي.
5. الخطوة 3: اضغط على "Generate Official Certificate (.docx)".
6. ستجد الشهادات الجاهزة داخل مجلد "generated_certificates".

* NOTE: This portable version does NOT require Python or any installation.
  It is 100% self-contained and ready to run on any 64-bit Windows PC.
